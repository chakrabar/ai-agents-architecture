# Snowy Codex Pet

This folder contains a Codex-compatible animated custom pet.

## Install

1. Create the custom-pet folder:

   ```text
   ~/.codex/pets/snowy/
   ```

2. Copy these two files into it:

   ```text
   pet.json
   spritesheet.webp
   ```

3. Restart or reload Codex. Snowy should appear in the custom-pet picker.

## Save or share

Keep this whole folder, or zip it, to back up or share the pet. Only `pet.json` and `spritesheet.webp` are required to install it; `qa/` contains optional validation and review artifacts.

## Note on sharing

Snowy is inspired by the Tintin character. Public distribution may be subject to the rights holder's terms.
